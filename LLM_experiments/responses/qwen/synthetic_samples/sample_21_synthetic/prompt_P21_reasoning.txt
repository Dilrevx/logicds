### Original Vulnerability

In the original code, if neither the Pre-Shared Key (PSK) extension nor the Key Share (KS) extension is present in the ServerHello message, the function proceeds without setting up a valid IKM. Instead, it uses a default, potentially predictable buffer for the IKM. This predictable IKM can be exploited by an attacker to reconstruct the session master secret, leading to potential eavesdropping or tampering with the encrypted communication.

### Key Concepts

- **Pre-Shared Key (PSK):** A shared secret between the client and server that can be used to establish a secure session without the overhead of a full handshake.
- **Key Share (KS):** Used in the Elliptic Curve Diffie-Hellman (ECDHE) key exchange mechanism, where both parties share ephemeral keys to derive a shared secret.
- **Initial Keying Material (IKM):** A critical piece of data used to generate the session master secret, which is essential for securing the session.
- **Predictable Buffer:** If the IKM is derived from a predictable buffer, it significantly reduces the security of the session, as an attacker can guess or compute the IKM and subsequently the session master secret.
