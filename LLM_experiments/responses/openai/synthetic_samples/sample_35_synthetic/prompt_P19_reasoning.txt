   The code assumes that AdminManager is implemented using the holder pattern, where a nested static class (SingletonHolder) lazily instantiates the singleton instance. This pattern is inherently thread-safe without needing explicit synchronization. Since SingletonHolder.INSTANCE remains unmodifiable after the first call through getInstance(), checking against it in the constructor helps determine if an instance has been created.
