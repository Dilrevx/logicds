Below is one acceptable repair. Instead of letting the application callback override a failed certificate check, the code now always performs the default verification first and only calls the app_verify_callback when the built‐in verification succeeds. This prevents an attacker from bypassing certificate verification by supplying a custom callback.

<repair>
        int ret = X509_STORE_CTX.verify_cert(ctxStore);
        if (ret <= 0) {
            i = ret;
        } else if (s.ctx.app_verify_callback != null) {
            i = s.ctx.app_verify_callback.verify(ctxStore, s.ctx.app_verify_arg);
        } else {
            i = ret;
        }
</repair>
