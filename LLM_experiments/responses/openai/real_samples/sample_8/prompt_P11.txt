     * To mitigate the Terrapin attack, we must never trust the preliminary “first KEX packet”
     * that might have been pre-read. Even if the algorithms appearing in the
     * first packet seem to match our expectations, we force the guess to be
     * considered wrong. This prevents a remote attacker from bypassing integrity
     * checks by omitting packets.
     */
    if (first_kex_packet_follows || session->send_first_kex_follows) {
        session->first_kex_follows_guess_wrong = 1;
        SSH_LOG(SSH_LOG_DEBUG,
                "Forcing first KEX packet to be ignored due to Terrapin mitigation.");
    }
