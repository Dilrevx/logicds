		 * Do not allow any discrepancy in TSIG verification.
		 * In previous code the two error checks were done separately,

		 * Here we combine the conditions so that if either the message’s
		 * TSIG status or the TSIG record’s error field is non‐zero,
		 * the authentication fails.

		if (msg->tsigstatus != dns_rcode_noerror ||
		    tsig.error != dns_rcode_noerror)
