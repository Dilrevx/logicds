Below is one example of a repair that stops using a fallback to basic authentication. Instead, when the SPNEGO check fails it now sets only a “Negotiate”‐type challenge header so that clients are not allowed to “downgrade” to basic auth. (Note that the actual header‐setting function name is illustrative; if your module does not have a negotiate‐only routine you may need to modify the header-setting code appropriately.) 

<repair>
    if (NGX_DECLINED == ngx_http_auth_spnego_basic(r, ctx, alcf)) {
        spnego_debug0("SPNEGO auth failed");
        /* Instead of falling back to a Basic header challenge, set only a Negotiate header.
         * This prevents malicious clients or misconfigured servers from downgrading to weak Basic authentication.
         */
        if (NGX_ERROR == ngx_http_auth_spnego_headers_negotiate_only(r, ctx, alcf)) {
            spnego_debug0("Error setting negotiate header");
            return (ctx->ret = NGX_HTTP_INTERNAL_SERVER_ERROR);
        }
        return (ctx->ret = NGX_HTTP_UNAUTHORIZED);
    }
</repair>

In this repair the module no longer calls ngx_http_auth_spnego_headers_basic_only but instead calls a routine (here, ngx_http_auth_spnego_headers_negotiate_only) that sets only the “WWW-Authenticate: Negotiate” header. This prevents a potential vulnerability that could be exploited via a fallback to basic authentication.
