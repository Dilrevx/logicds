Below is one way to repair the logical flaw. In the original code if basic auth was enabled the module called ngx_http_auth_basic_user(), but then if the result was anything other than NGX_DECLINED the function would fall through to later SPNEGO processing. That created a window where a client sending basic credentials (whether valid or invalid) might have been processed by SPNEGO even though basic auth was enabled. In the fix the function immediately returns if basic auth credentials were found (whether successful or failed) so that SPNEGO isn’t needlessly attempted.

<repair>
    if (alcf->allow_basic) {
        spnego_debug0("Detect basic auth");
        ret = ngx_http_auth_basic_user(r);
        /* If the basic auth function found credentials (whether valid or not)
         * then we must stop here and return the result immediately.
         * Note: NGX_DECLINED means that no basic authentication credentials were provided */
        if (ret != NGX_DECLINED) {
            spnego_debug1("Basic auth result: %d", ret);
            return ret;
        }
    }

    spnego_debug0("Performing SPNEGO auth process");
    
    /* Continue with the rest of the SPNEGO authentication process.
     * (The remaining SPNEGO logic that handles token challenge, etc.,
     * should be here, or return an appropriate status if token is not
     * present or authorization fails.) */

    // ... rest of SPNEGO authentication process ...

    return ret;
</repair>
