By changing the loop to start from index 0, the repair ensures that all certificates in the chain—from the leaf to the root—are inspected for invalid policy extensions. This modification effectively closes the vulnerability where a malicious CA could embed invalid policy extensions into the leaf certificate to bypass the intended security measures.
