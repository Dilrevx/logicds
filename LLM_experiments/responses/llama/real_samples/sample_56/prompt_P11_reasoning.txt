The repair I provided addresses the vulnerability of Improper Access Control in the Pypi calibreweb code. The vulnerability arises from the fact that the code does not properly check the user's role before allowing them to create or edit shelves.

In the original code, the check for the user's role is only performed when the "is_public" checkbox is selected. This means that a user without the required role can still create or edit a shelf by simply not selecting the "is_public" checkbox. This is a security vulnerability because it allows unauthorized users to perform actions that they should not be able to perform.

To fix this vulnerability, I modified the code to check the user's role at the beginning of the POST request, regardless of whether the "is_public" checkbox is selected. If the user does not have the required role, a flash message is displayed and the user is redirected to the index page.

I also added a check for the user's role when updating the "kobo_sync" field. This is because the original code only checked for the "config_kobo_sync" configuration option, but did not verify that the user had the required role to update this field.

Additionally, I changed the way the "is_public" and "kobo_sync" fields are updated. In the original code, these fields were updated based on the presence or absence of the corresponding checkboxes in the request form. However, this is not a secure way to update these fields, as it allows an attacker to manipulate the request form to update these fields arbitrarily. Instead, I updated the code to only update these fields if the corresponding checkboxes are explicitly selected in the request form.

Overall, the repair I provided addresses the vulnerability of Improper Access Control by ensuring that the user's role is properly checked before allowing them to create or edit shelves, and by updating the "is_public" and "kobo_sync" fields in a secure way.

Here are the specific changes I made:

* Added a check for the user's role at the beginning of the POST request
* Added a check for the user's role when updating the "kobo_sync" field
