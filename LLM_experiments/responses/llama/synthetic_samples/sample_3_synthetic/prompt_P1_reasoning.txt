**Identifying the root cause**

The root cause of the vulnerability lies in the fact that the OpenSSL code does not properly handle custom ciphers with an NID of `NID_undef`. When the `NID_undef` value is passed, the code should either reject the custom cipher or handle it in a way that prevents the NULL cipher from being used.
