### OSSL_PARAM_locate_const

Locate a constant parameter in a parameter list.

*   `params`: The parameter list to search.
*   `name`: The name of the parameter to locate.

Returns a pointer to the located parameter, or `NULL` if not found.

### OSSL_PARAM_get_octet_string

Get the value of an octet string parameter.

*   `p`: The parameter to retrieve.
*   `data`: A pointer to store the octet string data.
*   `len`: A pointer to store the length of the octet string.

Returns 1 on success, 0 on failure.

### HKDF_expand

Derive a key using the HKDF algorithm.

*   `input`: The input data to derive the key from.
*   `input_len`: The length of the input data.
*   `output`: A pointer to store the derived key.
*   `output_len`: The length of the derived key.

Returns 1 on success, 0 on failure.
