The vulnerability in the provided code snippet arises from the fact that `x509_verify_ctx_add_chain` does not store errors that occur during leaf certificate verification. This issue is particularly problematic when there is an installed verification callback that instructs the verifier to continue upon detecting an invalid certificate. To address this vulnerability, we need to ensure that any errors encountered during the verification process are properly stored and returned.

    }

    if (!x509_verify_cert_valid(ctx, leaf, NULL)) {
        ctx->error = X509_V_ERR_CERT_NOT_YET_VALID_OR_EXPIRED; // Store the error
        ret = 0;
