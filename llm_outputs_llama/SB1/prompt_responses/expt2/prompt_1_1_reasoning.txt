1.  **DH certificates require a CertificateVerify message**: When a server's certificate is a DH certificate, the client must send a CertificateVerify message to prove possession of the private key corresponding to the public key in the certificate. 2.  **The original code does not enforce this requirement**: The original code only checks if the peer is not null and if the type is a signing type. However, this check is not sufficient to prevent the vulnerability, as it does not take into account the type of the server's certificate.
