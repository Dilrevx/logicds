     ```c
     if (!x509_verify_ctx_validate_legacy_chain(ctx, chain, depth))

     if (!x509_verify_ctx_validate_legacy_chain(ctx, chain, depth)) {

By adding a call to `x509_verify_cert_error`, we ensure that the context records the exact error (in this case, `X509_V_ERR_INVALID_CERTIFICATE`) along with the depth and the problematic certificate (`last`).      if (!x509_verify_cert_valid(ctx, leaf, NULL)) {

By implementing these changes, the code now properly captures and reports errors at each step of the certificate verification process.
