### Understanding the Vulnerability

OpenSSL provides functionality to create custom ciphers using the `EVP_CIPHER_meth_new()` function and associated methods. These custom ciphers are intended to be used in encryption and decryption processes. However, there is a flaw in OpenSSL versions 3.0.0 to 3.0.5 where legacy custom ciphers passed to initialization functions like `EVP_EncryptInit_ex2()`, `EVP_DecryptInit_ex2()`, and `EVP_CipherInit_ex2()` are incorrectly handled. Instead of using the custom cipher directly, OpenSSL attempts to fetch an equivalent cipher from the available providers based on the NID passed to `EVP_CIPHER_meth_new()`. If `NID_undef` is used, OpenSSL mistakenly matches the NULL cipher, which does not perform any encryption, leading to plaintext being output as ciphertext.
