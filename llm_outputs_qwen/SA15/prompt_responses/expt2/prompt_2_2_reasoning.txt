### Understanding the Vulnerability

PEAP is a two-phase authentication protocol designed to provide strong authentication over insecure networks. In the first phase, the client and access point establish a secure tunnel using TLS (Transport Layer Security). In the second phase, the client authenticates to the authentication server using an inner method such as MSCHAPv2. The vulnerability lies in how `wpa_supplicant` handles the transition from Phase 1 to Phase 2. Specifically, if `wpa_supplicant` is configured to not verify the network's TLS certificate during Phase 1 and an attacker sends an `EAP-TLV Success` packet, the authentication process can be prematurely terminated, skipping the crucial Phase 2.
