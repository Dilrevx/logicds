### Vulnerability Context

In TLS v1.3, mutual authentication is a feature that ensures both the client and the server authenticate each other using certificates. This is particularly important in scenarios where the server needs to verify the identity of the client, such as in secure banking applications or enterprise networks. When mutual authentication is required, the client must provide a `Certificate` message followed by a `CertificateVerify` message to prove possession of the private key corresponding to the public key in its certificate. If the server does not enforce the receipt of these messages, a malicious client could connect without providing a certificate, leading to unauthorized access.
