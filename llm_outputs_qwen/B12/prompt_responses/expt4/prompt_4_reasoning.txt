The repair provided addresses a significant vulnerability in the wolfSSL library related to the TLS 1.3 handshake process, specifically in how it verifies the presence of the correct public key corresponding to the digital signature algorithm used by the peer. ### Vulnerability Analysis

In the original code, the function `DoTls13CertificateVerify` checks whether the peer has sent a signature algorithm and then verifies if the corresponding public key is present. However, the original checks do not properly enforce the requirement that the peer must have the correct public key for the specified signature algorithm. Instead, they log a warning message and continue processing, which can lead to insecure connections being established.
