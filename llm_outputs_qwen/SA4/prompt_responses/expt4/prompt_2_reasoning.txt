Specifically, the issue arises from the misuse of Associated Authenticated Data (AAD) as the Message Authentication Code (MAC) key. In cryptographic protocols, AAD serves as additional data that is authenticated but not encrypted. It is used to ensure that any modifications to the data being transmitted are detected, but it is not intended to serve as the MAC key itself.
