It is used to generate a message authentication code, which is then appended to the data to verify that it has not been altered during transmission. For AEAD (Authenticated Encryption with Associated Data) ciphersuites, the MAC key is distinct from the AAD; the AAD is used for additional authenticated data that needs to be included in the integrity check but not encrypted.

Consequently, an attacker can perform a man-in-the-middle attack, modify the data in transit, and still generate a valid MAC that passes the integrity check at the recipient's end, thereby compromising the security of the communication.
