The current code does not enforce this requirement for DH certificates, which can allow unauthorized access.

1. **Check for DH Certificates**: We need to determine if the peer's certificate uses a DH key. This can be done using OpenSSL functions that inspect the certificate's public key.

2. **Require CertificateVerify**: If the certificate uses a DH key, the function should require a `CertificateVerify` message. If the message is missing, an error should be raised.
