However, for RSA PKCS#1.5 signatures, it incorrectly returns `CommonsConstants.INVALID_PARAMETER` if the RSA key is not present. This does not align with the expected behavior of checking for a signature-key mismatch and should instead behave similarly to the other checks.

3. **General Consistency**: By making these changes, the code maintains a consistent pattern of checking for the presence of the correct key type for each signature algorithm and providing appropriate error messages when mismatches occur.
