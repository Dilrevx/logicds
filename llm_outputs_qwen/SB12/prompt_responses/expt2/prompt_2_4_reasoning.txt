### Vulnerability Overview

The vulnerability described pertains to a potential man-in-the-middle (MITM) attack on TLS 1.3 clients using the wolfSSL library. Specifically, malicious attackers positioned in a privileged network could impersonate TLS 1.3 servers and bypass authentication by sending mismatched signature algorithms. This means that even if the server's certificate does not match the signature algorithm used, the client might still proceed with the handshake, leading to a compromised secure connection.
