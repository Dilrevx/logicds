Below is one repair that prevents a malicious CA from bypassing the policy check. In the original code the loop only checks certificates starting at index 1 (skipping the leaf certificate at index 0). This means that if the leaf certificate asserts an invalid policy, it isn’t caught. The fix is to include the leaf certificate in the check. For example, you can change the for‑loop to start at index 0:

----------------------------------------------------------------
if (ret == X509PolicyChecker.X509_PCY_TREE_INVALID) {

    // Check every certificate in the chain (including the leaf certificate)
    for (int i = 0; i < ctx.chain.size(); i++) {
        X509Certificate x = ctx.chain.get(i);

        cbFailIf(x == null || (x.hashCode() & EXFLAG_INVALID_POLICY) != 0,
                 ctx, x, i, X509Error.X509_V_ERR_INVALID_POLICY_EXTENSION);
    }

    return 1;
}
----------------------------------------------------------------

This ensures that the invalid certificate policy in the leaf is no longer silently ignored, closing the vulnerability.
