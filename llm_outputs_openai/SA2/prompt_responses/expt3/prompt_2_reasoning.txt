This prevents an attacker from hiding an invalid policy only within the first certificate.

   This variable is initially set to false and is used to track whether any certificate in the chain triggers the invalid policy condition. When the loop finds a certificate that is either null or whose hash code indicates an invalid policy (by using the bitwise check with EXFLAG_INVALID_POLICY), it sets invalidPolicyFound to true and calls the failure callback. This ensures that the code acknowledges every instance of invalid policy issues.

   After iterating over all certificates, the code checks if invalidPolicyFound remains false.
