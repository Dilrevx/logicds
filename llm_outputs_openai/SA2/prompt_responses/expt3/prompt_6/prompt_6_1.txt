void validate_certificate_chain(Certificate *cert_chain[], int num_certs) {

    int i;

        if (cert == NULL || has_invalid_policy(cert)) {

            invalid_policy_found = 1;

    if (!invalid_policy_found) {
        fatal_internal_error("No certificate in the chain has an invalid policy; certificate chain structure is unexpected.");

Explanation of the Repair:
1. The iteration now begins at index 0 so that even the first certificate is checked.
2. A flag variable (invalid_policy_found) is introduced to track whether any certificate in the chain is identified as having an invalid policy.
3. After the loop, if the flag remains unset (meaning that no certificate was marked as having an invalid policy), fatal_internal_error() is called to signal an unexpected condition.

By applying these changes, the repair eliminates the risk of bypassing the certificate policy check and makes it much harder for a malicious CA to exploit the vulnerability.
