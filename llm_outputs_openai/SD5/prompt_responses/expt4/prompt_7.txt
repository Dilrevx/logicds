<repair>
    private AdminManager() {
        // Do not use the dynamic system property override for the admin provider.
        // Using the default provider prevents an attacker from substituting a malicious class.
        initProvider(DefaultAdminProvider.class);
    }
</repair> 

Explanation:
Instead of calling ADMIN_PROVIDER.getValue() (which allows a remote attacker to supply an arbitrary provider class via the system property), the repair hard‐codes the default provider (DefaultAdminProvider.class). This prevents privilege escalation via the external “admin.authorizedJIDs” (and related) system property manipulations.
