2. It also extracts the signature algorithm field from the outer certificate.
3. After both fields are read, we compare them (using a helper function like compareSignatureAlgorithms) to ensure the certificate hasn’t been tampered with or misconfigured.
4. If the algorithms differ, the function frees resources, asserts the error, and returns an error code.
