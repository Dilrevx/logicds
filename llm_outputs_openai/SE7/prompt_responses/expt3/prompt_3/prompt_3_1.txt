Below is one example of a repair. The issue is that the implementation was incorrectly allowing a number of NAS message types in plaintext. According to the vulnerability report, only the following plaintext messages are permitted:
 • Detach Request
 • EMM Information
 • EMM Status
 • Attach/Service Reject (and/or Service Reject) only when the emm cause equals 25

One repair is to restrict the plaintext acceptance to only those messages. For Attach or Service Reject cases, the code must additionally verify that the emm_cause equals 25. For example:

-------------------------
/* Assume emm_cause is available in the current context */
if (sec_hdr_type == LIBLTE_MME_SECURITY_HDR_TYPE_PLAIN_NAS) {
    switch (msg_type) {
        case LIBLTE_MME_MSG_TYPE_DETACH_REQUEST:
        case LIBLTE_MME_MSG_TYPE_EMM_INFORMATION:
        case LIBLTE_MME_MSG_TYPE_EMM_STATUS:
            /* Allowed plaintext messages */
            break;

        case LIBLTE_MME_MSG_TYPE_ATTACH_REJECT:
        case LIBLTE_MME_MSG_TYPE_SERVICE_REJECT:
            /* Only allow if the emm cause is 25 */
            if (emm_cause != 25) {
                logger.error(
                    "Plain NAS message MSG_TYPE=%02X with SEC_HDR_TYPE=%02X is allowed only with emm_cause=25, got emm_cause=%d",
                    msg_type,
                    sec_hdr_type,
                    emm_cause
                );
                return SRSRAN_ERROR;
            }
            break;

        default:
            logger.error(
                "Not handling NAS message MSG_TYPE=%02X with SEC_HDR_TYPE=%02X without integrity protection!",
                msg_type,
                sec_hdr_type
            );
            return SRSRAN_ERROR;
    }
}

-------------------------

Step by step explanation:
1. We remove all the message types that were improperly allowed (such as Identity Request, Authentication Request/Reject, Detach Accept, Tracking Area Update Reject).
2. We leave in plaintext processing only for Detach Request, EMM Information, and EMM Status.
3. For Attach or Service Reject messages, we add a condition to verify that the emm_cause equals 25.
4. If a plaintext message does not fall within the allowed categories, the function logs an error and returns an error code.

This repair thus ensures only the intended NAS messages get processed in plaintext, preventing an attacker from exploiting the ability to send unauthenticated NAS messages.
