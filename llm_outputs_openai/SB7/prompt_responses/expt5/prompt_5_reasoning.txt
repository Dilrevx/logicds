This preservation of the original error is important because later in the process, callbacks or additional logic might allow the verification process to continue even if an error occurred. Recording the error ensures that later diagnostics or error handling routines have access to the true failure condition of the leaf certificate rather than an error that might be overwritten by subsequent operations.

By moving the chain duplication to after the certificate validations, the repair avoids the original problem where any memory errors or other issues related to the chain duplication could obscure the earlier validation errors.
