This is a critical issue, as it can lead to the acceptance of invalid or malicious certificates.

The root cause of this vulnerability lies in the way the function handles the return value of the certificate verification process. When the verification fails, the function returns a negative value, but this value is not properly propagated to the caller. Instead, the function returns a positive value, indicating success, which is misleading and incorrect.
