    ROLE_SERVER

/*
 * Helper function: remove_extension_marker
 * Searches for marker in the provided methods string and truncates it (by inserting
 * a string terminator) if the marker is found.
 */
static void remove_extension_marker(char *methods, const char *marker) {
    char *p = methods ? strstr(methods, marker) : NULL;
    if (p) {
        /* Truncate string at the marker's begin */
        *p = '\0';
    }
}

Explanation:

1. The function remove_extension_marker() looks for a specified marker in the key exchange method string. When found, it truncates the string by writing a null terminator at the marker position.

2. The process_kex_methods() function checks the session role. If it is a client session, it sanitizes session->client_kex_methods; if it is a server session, it sanitizes session->server_kex_methods. This dual-check ensures that both endpoints enforce strict negotiation rules.

3. By removing any additional or downgraded negotiation parameters (such as those added by insecure extensions), the patch prevents an attacker from bypassing the integrity checks on either side during the SSH handshake.
