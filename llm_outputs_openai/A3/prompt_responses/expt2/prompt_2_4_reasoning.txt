By checking the legacy origin directly, the repair ensures that any cipher known to be legacy is properly flagged.

The second added condition, (cipher == NULL && ctx->cipher != NULL && EVP_CIPHER_is_legacy(ctx->cipher)), handles the case where the local cipher variable is null, but the context’s cipher pointer is set. This second check is crucial for scenarios where the local variable might have been modified or not set while the context still retains the necessary legacy indicator.
