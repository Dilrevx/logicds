    public static Frec lookup_frec(int id, byte[] hash, int family, int fd) {
        for (Frec f = Daemon.frec_list; f != null; f = f.next) {
            // Ensure the query has a valid destination and that its
            // reply destination (address family and port) matches the reply.
            if (f.sentto != null 
                    && f.new_id == id
                    && f.sentto.getPort() == fd
                    && (   (family == 4 && f.sentto.getAddress() instanceof java.net.Inet4Address)
                        || (family == 6 && f.sentto.getAddress() instanceof java.net.Inet6Address))
                    && (hash == null || java.util.Arrays.equals(hash, f.hash))) {
                return f;
            }
        }
        return null;
    }

Explanation:

The repair adds additional checks to verify that the reply corresponds exactly to 
the pending forwarded query by matching the reply’s destination port (using the 'fd'
parameter) and the address family (IPv4 vs IPv6) by checking the type of the address in
f.sentto. This ensures that when a DNS reply is received, it is matched against the query 
that originated from the same destination address/port – in line with RFC5452 – 
thus mitigating the forged reply (cache poisoning) vulnerability.
